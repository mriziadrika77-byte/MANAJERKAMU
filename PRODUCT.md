# PRODUCT CONTEXT: MANAJERKAMU

## 1. Product Identification
- **Name**: MANAJERKAMU
- **Tagline**: One Person. Multiple Activities. One Integrated System.
- **Category**: AI-Powered Integrated Work and Income Management Platform
- **Type**: Interactive Web Application (Frontend-Only Prototype)
- **Primary Users**: Freelancers, gig economy workers, professional service providers, independent business owners, multi-income workers.

## 2. Core Problem Solved
Managing multiple fragmented income sources and work activities in one unified command center with direct visibility into real net earnings (revenue minus operational expenses), time capacity allocation, and financial planning.

## 3. Key Modules
1. **Overview Dashboard**: Personal command center with primary emphasis on Net Income, cash trends, activity contribution, and workload alerts.
2. **My Activities Portfolio**: Management across 4 activity archetypes (Project-based, Platform-based, Session-based, Business-based).
3. **Income & Expense Records**: Transactional cashflow, incremental payment reconciliation (Paid, Partially Paid, Pending), and operational cost tracking.
4. **Workload & Schedule**: Weekly/monthly calendar, capacity tracking, task management, and visual conflict detection.
5. **Financial Planning & Forecasting**: Monthly/annual target setting and dynamic scenario modeling (Conservative, Current, Optimistic).
6. **AI Personal Assistant**: Rule-based local analytics engine providing grounded insights on highest margin activities and time efficiency.
7. **Analytics & Reports**: Trend analysis, expense breakdown by category, activity performance metrics, and CSV export.
8. **My Documents**: Local metadata repository for contracts, invoices, project reports, and payment receipts.
9. **Account Profile & Settings**: User preferences, Light/Dark mode, currency selection, and verified demo data reset.

## 4. Technical Constraints
- 100% Client-side state & LocalStorage persistence.
- No backend server, no external API keys, no paid LLM dependencies.
- All financial metrics computed by a single deterministic calculation engine.
